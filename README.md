# ShopLite (testbed)

A small e-commerce backend used as a **controlled test-bed** for the
semantic-doc-agent project. Its commit history is *scripted on purpose*: it contains
deliberate structural changes, local changes, and one "trap" commit, so a documentation
agent can be evaluated against known ground truth.

This is demo code. It is in-memory, standard-library only, and not meant for production.

Modules: auth, inventory, payments, notifications, orders, analytics.
